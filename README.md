# 番茄钟悬浮小窗

一个轻量、绿色免安装的番茄工作法桌面小工具。主卡悬浮于桌面任意角落，浅色马卡龙配色，支持专注/短休息/长休息三个阶段、待办清单与按天历史归档、完成一颗番茄自动在桌面贴一颗贴纸。

纯标准库实现（tkinter），零第三方依赖，双击即可运行，数据全部本地持久化。

---

## 功能特性

- **番茄周期**：专注 → 短休息，每 4 个专注进入一次长休息；三阶段时长可在设置里调整（1–120 分钟）。
- **悬浮主卡**：可拖动、可一键置顶（图钉）、支持点击穿透的透明角落，随时置顶不挡操作。
- **待办清单**（SQLite）：增删改、点选设当前任务、从面板一键开番茄；完成的任务自动收起、跨天自动归档。
- **按日归档**：历史待办按天浏览（只读快照），完成数按天落账，保留近 370 天。
- **统计视图**：按天查看历史完成数。
- **桌面贴纸墙**：每完成一个专注，桌面贴一颗贴纸，可整体开关。
- **提示音**：专注/休息结束时播放，可用右上角关闭音效。
- **单实例**：重复打开会提示"已在运行"，不会双开互踩配置。
- **健壮退出**：退出前全量落盘，进程立即结束，不会残留挂死进程。

## 快速开始

需要 Python 3.10+（推荐 3.12），无需安装任何第三方库。

**方式一：双击启动**

双击根目录的 `番茄钟.bat`（自动在 `pyw` / `pythonw` / `py` / `python` 之间选一个无控制台的解释器运行）。

**方式二：命令行**
```bash
python main.py
```

## 使用说明

- **主卡**：点按中间按钮开始/暂停；`重置`回到满时长；`跳过`结束当前阶段（不计入统计）；点左上角按钮可在专注/短休/长休间切换。
- **右键菜单**：打开待办清单、统计、置顶、贴纸墙、时长设置、关闭。
- **待办面板**：左侧输入框添加任务（文字上限 60 字，可附带 200 字备注）；`▶` 一键选中并开始该任务的番茄；勾选完成；顶部可翻看历史日期。

## 数据与持久化

| 文件 | 内容 |
|------|------|
| `config.json` | 时长、今日统计、按天历史、窗口位置、置顶/贴纸开关（低频设置） |
| `todos.db` | 待办清单（SQLite，高频增删改查） |
| `run.lock` | 单实例锁（进程退出/被杀由操作系统自动释放） |

所有数据都保存在应用根目录，删除即可完全卸载。

## 计时策略

以 `time.monotonic` 的截止时刻为准：控制器每拍把单调时钟算出的真实剩余秒数写回引擎，事件循环即使卡顿几秒，恢复后也会立即校准，不依赖"每秒减一"的累积，也不会累积漂移。

## 已知说明

- 用户退出走 `os._exit(0)`：本机 Tk 8.6 销毁这套窗口树（透明键 + 置顶自绘 + 多 Toplevel）时可能触发堆损坏导致进程挂死。所有状态在退出前已持久化，Windows 会自动回收窗口与文件锁，因此这是刻意的设计而非缺陷。
- 建议在有屏幕的任务栏上悬浮使用，透明键 `#ff00fe` 仅用于窗口层，不影响绘制。
